# 代理、模型配置与卸载安全回归结果

验证日期：2026-09-08。对象：当前工作区的模型 Token 配置、代理与同步保护，以及 `ccsw uninstall` 实现（基于 v0.1.4）。

## 已执行

- Docker Linux ARM64，`rust:1.95.0-bookworm`。
- 镜像内 Rustfmt、Clippy（warnings 为错误）通过。
- 镜像内 Rust 测试：101 项单元测试 + 3 项原有集成测试 + 2 项卸载集成测试，全部通过。
- 同一最终镜像中，以 root 执行 33 项安全场景全部通过。
- 以 UID 10001 执行相同场景：32 项通过，修改文件所有者的场景因需要 root 而跳过；该场景已在 root 轮次通过。
- 本机 macOS 的 Rustfmt、Clippy、106 项 Rust 测试和 Release 构建通过。

容器关闭网络，根文件系统只读，仅临时目录可写；没有挂载宿主机 HOME 或 Docker socket。所有卸载命令只操作临时 HOME，没有对开发者实际配置执行卸载。

## 覆盖范围

预览无副作用、未提供 `--yes` 时仅预览、重复卸载、正常清理、中文和自定义路径、其他应用文件和聊天记录保留、外部 Claude 目标保留、符号链接文件/父目录/锁/备份拒绝、Unix 硬链接拒绝、HOME 外路径与 `..` 拒绝、目录冒充文件、损坏配置/注册表/Claude 设置、共享状态拒绝、跨用户文件拒绝、不安全目录权限、会话锁/配置锁竞争、自启归属不明与禁用失败、已确认自启项清理、伪造 PID 不终止无关进程、另一个代理保持运行、80 个随机命名无关文件内容不变、错误 token 无法停止代理、非回环代理地址拒绝。

拒绝场景比较执行前后文件清单与 SHA-256；正常卸载验证端口可重新绑定、受管文件清理、Claude 无关字段和其他文件内容保留。

## 新增功能回归

- 真实 HTTP 代理请求验证三种协议的输出 Token 上限，以及较小请求值保持不变。
- Rust 测试覆盖模型表单参数校验、禁用模型编辑、thinking budget 冲突、UTF-8 字节拆分、混合 SSE 换行、单次流结束、异常断流、流式空闲超时和响应体大小限制。
- 同步测试覆盖外部修改触发暂停，以及缺失字段与显式 null 的区分。
- Docker 额外验证卸载保留手动修改的模型字段、旧快照缺失时保留未验证字段、普通 Stop 面对伪造 PID 不终止无关进程。

## 验证边界

Linux 自启成功/失败测试使用隔离脚本模拟 systemctl 的返回，不代表验证真实 systemd 用户会话。Windows/macOS 自启管理器的完整卸载尚未在实机执行；跨平台卸载集成测试已加入仓库，等待相应 CI 执行。

这些测试不构成对恶意同权限进程并发替换目录、硬件故障或所有磁盘 I/O 故障的绝对保证。中途 I/O 错误会报告卸载未完成，需修复后重试。程序二进制保留；无法确认归属的 Claude 设置及备份保留；HOME 外配置和不安全路径拒绝自动清理。

补充验证：加入模型表单 `Alt+1` 快捷键后，本机完整 Rust 回归为 107 项（102 单元 + 5 集成）全部通过，Rustfmt 与 Clippy 通过。上述 Docker 结果来自加入该快捷键前的构建。
